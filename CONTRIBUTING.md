# Contributing

## Project Scope

World Forge is a public static demo and offer page.

## Good Contributions

- clearer copy
- better examples
- improved accessibility
- better validation
- small UI improvements
- documentation fixes

## Not In Scope Yet

- backend
- accounts
- payments
- external AI calls
- database
- tracking or analytics

## Local Check

Before opening a pull request:

```bash
python3 scripts/verify_public_demo.py
```

## Safety

Do not include secrets, private paths, customer data, or internal vault material.

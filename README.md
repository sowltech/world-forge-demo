# World Forge Public Demo v0.1

## What It Does

World Forge turns a raw world idea into a structured World Bible.

## How To Run Locally

```bash
python3 -m http.server 4173 --directory "01_Projects/World Forge/public_demo"
```

Open:

```text
http://localhost:4173
```

## Public Deployment

Deploy only this folder:

```text
public_exports/world-forge-demo/
```

Do not deploy the full private repo.

## Features

* Browser-only generation
* Markdown export
* JSON export
* Sample concept loader
* No backend
* No external AI calls
* No accounts
* No payments
* No analytics

## Current Limits

* Template-based
* Single-world generation
* No saved accounts
* No database
* No AI model integration yet

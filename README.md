# World Forge Public Demo v0.1

## What It Does

World Forge turns a raw world idea into a structured World Bible.

## Live Demo

Open the static demo directly in a browser or serve it locally:

```bash
python3 -m http.server 4173
```

Then visit:

```text
http://localhost:4173
```

## Public Deployment

Deploy the root of this public repository.

* Browser-only generation
* Markdown export
* JSON export
* Sample concept loader
* No backend
* No external AI calls
* No accounts
* No payments
* No analytics

## Current Limits

* Template-based
* Single-world generation
* No saved accounts
* No database
* No AI model integration yet
